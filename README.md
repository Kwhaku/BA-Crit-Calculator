# 断箭 · 重创率计算器 / Broken Arrow · Critical Hit Calculator

《断箭》的重创（暴击）概率计算器。选弹药、选目标、选朝向和距离，直接算出这一发的**重创概率**和**保底重创次数**。

单文件 HTML，双击就能用，不联网、不安装。数据来自本机解包，公式来自反汇编。

## 公式

```
q = ⌊K ÷ 100⌋
p = (K − 100q) × (D ÷ HP_max) + 0.02        （上限 1）
n = q + 1  若 p ≥ 随机数，否则 n = q
```

- **K**：弹药的 `CriticMultiplier`（本工具内置 267 种）
- **D**：装甲计算后的最终伤害
- **HP_max**：目标最大生命
- **p**：追加一次重创的概率
- **q**：保底重创次数（百位）
- **n**：这一发实际挂几次重创

**重创不减少生命值**，只让目标的探测 / 瞄准 / 装填 / 机动变差（黄 ×1.5~2.0，红更重，先吃两个黄才会出红）。

### 两个容易被忽略的推论

1. **重创率和伤害挂钩**——打侧面/后部（装甲低、伤害高）重创率显著更高
2. **权重百位是保底次数**——`K=202`（ATACMS、匕首）不是「低权重」，而是**每发保底挂 2 次重创**；`K=199`（集束弹）是保底 1 次 + 99% 再来一次

## 功能

| 模块 | 说明 |
|---|---|
| 弹药 | 267 种弹药，可搜索；自动带出伤害、穿深（近/远）、射程、装甲类型 |
| 目标 | 545 个单位，可搜索；自动带出生命与四向装甲（白甲/黄甲） |
| 朝向 | 正面 / 侧面 / 后面 / 顶部 |
| 距离 | 滑杆 0–射程；动能弹穿深随距离线性衰减，化学能不变 |

| 排行榜 | 当前目标/朝向下，全部弹药的暴击率排序（前 30） |

## 数据与方法

公式不是拟合出来的，是在 `GameAssembly.dll` 里逐条读出来的：

| 环节 | 位置 | 内容 |
|---|---|---|
| 权重来源 | `Ammunitions.0xA0` | 每发弹药自带 `CriticMultiplier` |
| 打包 | `ShellHitSystem.DealUnitDamage` @ `0x7FD5CB` | 伤害 ÷ 最大生命 → `HPLossRate`，与 K 一起塞进 `CriticalDamage` |
| 结构体 | `CriticalDamage` | `HPLossRate @0x0`、`AmmoCriticMultiplier @0x4` |
| 掷骰 | `CriticalEffectSystem.Update` @ `0x7EEA38–0x7EEAA9` | `⌊K/100⌋` → 余数 × `HPLossRate` + 0.02 → 与随机数比较 → n |
| 基础概率 | `BuffConfig.CriticalBaseProbability` | 构造函数默认 `0.05`，实际生效 **`0.02`**（`GameConfig` 资产覆盖） |
| 红色阈值 | `BuffConfig.RedCritsActivationThreshold` | 实际值 **`2`**：先吃两个黄，之后才可能出红 |

伤害公式：

- **动能**：`穿深 ≥ 装甲` 全伤；否则 `2 − 装甲/穿深`，下限 `0.1`；`穿深 ≤ 装甲/2` 时归零
- **化学能**：`穿深² ÷ (穿深² + 装甲²)`

### 交叉验证

- **运行态**：Frida 钩子在真实对局中采集 139 发样本，覆盖 `K = 1 / 5 / 98` 三档，预测与实测偏差均 < 0.4 次
- **社区解包**：第三方项目 BA-Units 的 630 条弹药权重与本表 **630/630 一致**
- **独立推导**：俄语站 [strategycon.ru](https://strategycon.ru/articles/broken-arrow-stats-guide) 独立解包得出同一公式（含 `⌊K/100⌋` 与 `n = q+1`）

## 已知限制

- 改装（装甲包、武器改型）对装甲和伤害的影响**未纳入**首版，用的是基础配置
- 攻顶弹、爆炸溅射、APS 拦截等未建模；本工具只算「单发命中 + 装甲结算」这一条链
- 目标是步兵时用单一护甲值，未区分掩体与烟幕
